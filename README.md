# imputation_accuracy_GC

This directory contains two python scripts used for analysis of data in Cook et al "Genomic analyses identify 15 susceptibility loci and reveal HDAC2, SOX2-OT, and IGF2BP2 in a naturally-occurring canine model of gastric cancer" PNAS 2025.
The scripts are used to calculate the genotype concordance, or agreement, between samples (dogs) run on different genotyping arrays and imputed up to whole-genome level. The samples need to have the same name.

1. imputation_accuracy.py
This script uses traw files (generated by PLINK using --recode A-transpose) as input. These have genotypes coded as 0, 1, 2.
The output files are .tsv and are used for input into the next script (analysisOfTSV.py).
For each pair of files, this goes through and finds the samples in common in both files, then looks at the bp positions in common for each chromosome in both files, and then uses these to take the difference of the genotypes for each position (genotype code for file 1 - genotype code for file 2). The output is a matrix with a single number representing the genotype differences for each dog and each position in common between the two files. A number in the output matrix of 0 means the two files had the exact same genotype.
The number of chromosomes (1-38 autosomes in dog), the genotype size and type of data for the pairwise comparison files (173k, 220k, 670k datasets; genotyping array, imputed data) can be adjusted.

3. anaysisOfTSV.py
This script uses tsv files (as output by imputation_accuracy.py script above) as input.
This scripts calculates the concordance for each site and for each dog from the pairwise comparisons represented in the matrix .tsv files.
The output files are .csv for the concordance per individual (dog in this case) and .csv for the concordance per bp site. And a histogram for concordance per individual is also output (.pdf).

Modify the file names and other options (e.g., number of chromosomes) and then to run the scripts simply type:
python <name of script>
